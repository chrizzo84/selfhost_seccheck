# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment,
insults and personal attacks are not tolerated in issues, pull requests or any other project space.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer
([@chrizzo84](https://github.com/chrizzo84)) privately, for example through a
[private security advisory](https://github.com/chrizzo84/selfhost-seccheck/security/advisories/new) if no other
private channel is available. Reports are handled confidentially.

Maintainers may remove, edit or reject contributions that do not follow this code and may block contributors who
repeatedly or seriously violate it.
